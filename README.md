# 🌸 NammaVastra – Saree Market Insight App

NammaVastra is an Android application developed using Kotlin and Firebase to support saree businesses, weavers, and customers through a digital platform for saree management and market insights.

---

# 📱 Features

✅ Splash Screen with Logo  
✅ Weaver Story Section  
✅ Upload Saree Images  
✅ View Saree Gallery  
✅ Price Calculator  
✅ AI Trend Generator  
✅ Firebase Firestore Integration  
✅ Firebase Storage Integration  
✅ Modern Material UI Design  

---

# 🛠️ Technologies Used

- Kotlin
- Android Studio
- Firebase Firestore
- Firebase Storage
- XML Layouts
- Material Design 3
- MVVM Architecture
- Coil Image Loading Library

---

# 📂 Modules

## 🔹 Splash Screen
Displays app logo during launch.

## 🔹 Home Screen
Main dashboard containing all app features.

## 🔹 Weaver Story
Shows stories and details about saree weavers.

## 🔹 Upload Saree
Allows users to upload saree images and information.

## 🔹 Gallery
Displays uploaded saree collections.

## 🔹 Price Calculator
Calculates saree pricing based on selected values.

## 🔹 AI Trend Generator
Provides AI-based saree trend suggestions.

---

# ☁️ Firebase Services

## Firebase Firestore
Used to store saree information and app data.

## Firebase Storage
Used for storing uploaded saree images.

---

# 🏗️ Architecture

The project follows **MVVM Architecture** for clean and scalable code management.

# 🚀 Installation

## Step 1: Clone Repository

```bash
git clone https://github.com/Hemanthgouda/NammaVastra.git
```

## Step 2: Open in Android Studio

Open Android Studio → Open Project → Select NammaVastra Folder

## Step 3: Connect Firebase

Connect Firebase Firestore and Storage to the project.

## Step 4: Run the App

Run the application on Emulator or Android Device.
